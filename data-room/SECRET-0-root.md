# Origin Title Wallet — Data Room

**The closing file that never gets lost.**

Every real estate closing produces a stack of paper — deeds, settlements, wire confirmations, identity verifications, title searches. That paper goes into a filing cabinet at an attorney's office. When the attorney retires, the cabinet moves. When the firm closes, the cabinet disappears.

The Origin Title Wallet replaces the filing cabinet with a permanent, encrypted, signed digital record — attached to the **property**, not to a person or firm. Different parties see different things. The deed gets printed with a QR code linking to the wallet. The next title search on that property takes 15 minutes instead of 4 hours.

> "The registry is a filing cabinet. We're the security system."
> — Tracie, title insurance attorney

## How This Data Room Works

This data room uses the same infrastructure as the title wallet itself:

- **Each section** is a signed secret on Polygon — immutable, timestamped, independently verifiable
- **Updates** are added as notes on each secret (Last In, First Out — latest always on top)
- **Content** is stored on IPFS — decentralized, permanent, content-addressed
- **Access** is controlled by encryption — share a link, recipient decrypts with their key
- **Bridge notes** on this root secret link to each section by on-chain address

You are reading signed, encrypted, blockchain-verified documents right now. This is the product.
